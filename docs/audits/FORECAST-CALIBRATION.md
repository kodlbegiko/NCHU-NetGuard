# Conditional forecast calibration

PredictionEngine now uses duration-weighted rate percentiles rather than giving a quarter-second sample the same weight as a five-second sample. A >2x median change across equal-duration halves suppresses extrapolation; this is a conservative heuristic, not a confidence interval. A caller-confirmed exhausted local budget does not need a rate estimate. The offline walk-forward backtest trains only on preceding contiguous samples and evaluates the first observed directional/total crossing in held-out intervals. It reports resolved, interval-consistent and right-censored origins separately. Fixture consistency does not establish real-world calibration, completeness or provider balances. Real M4/local scope evidence and actual history calibration remain open.
