# Native interface counter source candidate

The previous AF_LINK getifaddrs data exposed a 32-bit Darwin if_data byte counter. Casting to UInt64 does not extend its source range. The candidate reads the documented PF_LINK/IFMIB_IFDATA/IFDATA_GENERAL interface MIB instead, verifies the returned name, index, structure size and 64-bit fields, and fails closed without a 32-bit fallback. getifaddrs remains address/link discovery only. Interface-index changes discard a counter interval, missing network identity keeps bytes unattributed. These are ephemeral observations and not persistent device identity, VPN deduplication, Internet-only bytes or proof of accuracy. The host check reads loopback twice and prints only compatibility, not counters. Tests cover crossing 2^32, generation changes and absent scope identity. Actual M4 controlled traffic and >4GiB comparison remain required. Sources: https://developer.apple.com/documentation/kernel/ifmibdata ; https://manp.gs/mac/4/ifmib ; https://github.com/apple/darwin-xnu/blob/main/bsd/net/if.c (32-bit copy); https://milen.me/writings/macos-network-metrics-sysctl-net-rt-iflist2/ (reported routing MIB truncation). No third-party source code imported.
