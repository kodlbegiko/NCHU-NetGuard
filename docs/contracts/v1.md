# R4.0 shared contract baseline (draft v1)

Status: initial contract draft; not frozen; broad parallel development remains locked.
All eight named contracts have initial Swift model implementations. ScopedCounterAccumulator is integrated into the legacy app. RecoveryTransaction is a pure state machine; UsageMigration validates persisted legacy data. These are not a frozen ABI or proof of host-side transactional support.

| Contract | Required fields / semantics |
|---|---|
| TrafficSnapshot | schemaVersion, timestamp, interface identity, UInt64 rx/tx bytes, quality; missing/reset/duplicate => unknown, never silently treated as zero measured |
| NetworkSnapshot | version, observedAt, stable service ID, interface, routes, IPv4/IPv6, reachability and quality; no default guessed identity |
| QuotaProfile | version, provider ID, scope, separate rx/tx/total limits in bytes, unit definition, reset time zone, policy source/version |
| PolicyDecision | version, decision ID, input snapshot IDs, reason, priority, authorization required, expiry, dry-run result |
| NetworkAction | version, transaction ID, allowlisted operation, target service ID, expected preconditions/postconditions, timeout, explicit authorization |
| RecoverySnapshot | version, transaction ID, exact prior owned settings, timestamp, integrity and external-change conflict check |
| ProtectedWorkflow | version, workflow ID, owner consent, process identity, start/expiry, protection scope |
| EventRecord | version, event ID, time, category, correlation ID, redacted reason, outcome, error code |

All schemas require version checks, typed errors and fixtures; unknown is not safe, no invented defaults. Traffic measurement boundary and VPN deduplication must be defined before integrating into app. Policy evaluation is pure; mutations are serialized in a separate adapter, with journal-before-write and verified rollback. No credentials, raw user IP or personal paths in logs by default.

Unlock gates: reviewed contracts, compiled shared package, golden fixtures, passing CI, path ownership, no unsafe mutation in CI, explicit approval from integration owner. None is inferred from this draft alone.

## Recovery and persistence invariants

RecoveryTransaction emits effects only. The caller must durably persist prepared/applied/committed/rolledBack entries and execute atomic compare-and-swap against a verified adapter revision. Unknown write outcomes, conflicting external edits, malformed journals and unsuccessful rollback must stop in safe mode. A boolean in a pure test is not system authorization. The real adapter remains prohibited until authorization, journal durability, serialized execution and macOS conflict detection are implemented and tested.

UsageMigration accepts legacy unversioned data and schema version 1, validates calendar dates and nonnegative integer byte counts, gives scoped counters precedence over legacy aliases, and does not import stale hardware baselines or unsafe controls. The app preserves invalid source data and archives previous-day raw data before replacing it. History conversion to SQLite remains open.
