# R4.0 shared contract baseline (draft v1)

Status: initial contract draft; not frozen; broad parallel development remains locked.
All eight named contracts have initial Swift model implementations. ScopedCounterAccumulator is integrated into the legacy app. RecoveryTransaction is a pure state machine; UsageMigration validates persisted legacy data. These are not a frozen ABI or proof of host-side transactional support.

| Contract | Required fields / semantics |
|---|---|
| TrafficSnapshot | schemaVersion, timestamp, interface identity, UInt64 rx/tx bytes, quality; missing/reset/duplicate => unknown, never silently treated as zero measured |
| NetworkSnapshot | version, observedAt, stable service ID, interface, routes, IPv4/IPv6, reachability and quality; no default guessed identity |
| QuotaProfile | version, provider ID, scope, separate rx/tx/total limits in bytes, unit definition, reset time zone, policy source/version |
| PolicyDecision | version, decision ID, input snapshot IDs, reason, priority, authorization required, expiry, dry-run result |
| NetworkAction | version, transaction ID, allowlisted operation, target service ID, expected preconditions/postconditions, timeout, explicit authorization |
| RecoverySnapshot | version, transaction ID, exact prior owned settings, timestamp, integrity and external-change conflict check |
| ProtectedWorkflow | version, workflow ID, owner consent, process identity, start/expiry, protection scope |
| EventRecord | version, event ID, time, category, correlation ID, redacted reason, outcome, error code |

All schemas require version checks, typed errors and fixtures; unknown is not safe, no invented defaults. Traffic measurement boundary and VPN deduplication must be defined before integrating into app. Policy evaluation is pure; mutations are serialized in a separate adapter, with journal-before-write and verified rollback. No credentials, raw user IP or personal paths in logs by default.

Unlock gates: reviewed contracts, compiled shared package, golden fixtures, passing CI, path ownership, no unsafe mutation in CI, explicit approval from integration owner. None is inferred from this draft alone.

## Recovery and persistence invariants

RecoveryTransaction emits effects only. The caller must durably persist prepared/applied/committed/rolledBack entries and execute atomic compare-and-swap against a verified adapter revision. Unknown write outcomes, conflicting external edits, malformed journals and unsuccessful rollback must stop in safe mode. A boolean in a pure test is not system authorization. The real adapter remains prohibited until authorization, journal durability, serialized execution and macOS conflict detection are implemented and tested.

UsageMigration accepts legacy unversioned data and schema version 1, validates calendar dates and nonnegative integer byte counts, gives scoped counters precedence over legacy aliases, and does not import stale hardware baselines or unsafe controls. The app preserves invalid source data and archives previous-day raw data before replacing it. Daily historical summaries now have a SQLite migration; richer scoped/time-series history remains open.

## Wire compatibility candidate

The current Swift model wire format is a **candidate** v1 (not a frozen ABI). Required field names are exactly the Codable names in the eight literal fixtures in Tests/NetGuardCoreTests/ContractCompatibilityTests.swift. The shared Swift default JSONEncoder/JSONDecoder date encoding is numeric seconds since 2001-01-01 UTC; UUID is a string; byte counters are nonnegative UInt64 integers. External provider JSON and daily-state migration have separate schemas and must not be interpreted as these shared contracts.

Consumers must use decodeValidated at untrusted input boundaries. Missing or unsupported schemaVersion, missing required fields, unknown enum cases, and invalid invariants fail closed. Unknown extra fields within v1 may be ignored; optional additive fields must have backwards-compatible semantics. Required-field additions, removals, renaming, unit changes and changed enum semantics require an ADR, new version, migration and compatibility fixtures. JSON round trips are semantic, not byte-for-byte canonicalization. No signature, digest or authorization is established by decoding alone.

The fixtures cover all eight types, round trip, unknown additive fields, unsupported version and missing version. Public Swift construction APIs are available; engineering semantic review and additional negative tests are recorded in [v1-semantic-review.md](v1-semantic-review.md). Exact-HEAD integration coverage and owner approval remain open. Do not unlock broad parallel development solely because the fixtures exist.

See the semantic review for the precise distinction between the implemented observational wire schema and the aspirational execution contracts. Shared v1 is not frozen.

Machine-readable freeze candidate: [registry-v1.json](registry-v1.json). The Python registry gate ties the eight golden fixtures to named models and validators; Swift golden tests check actual encoded values. Consumer inventory, drift review across releases and integration owner approval remain open. Registry status is deliberately not frozen.

Recovery persistence callbacks distinguish a proven pre-write failure from unknown outcome. Unknown post-apply or commit persistence must stop in safe mode; the bool compatibility method maps false to unknown. Advisory lock and fsync in the candidate journal do not constitute real adapter authorization or hardware durability proof.
